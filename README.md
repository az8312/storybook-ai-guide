# 📖 繪本創作 AI 引導腳本專案

本專案提供一套「循序漸進式」的 AI 系統提示詞（System Prompt），專為國小至國中學生設計，協助學生依步驟完成故事大綱、書名選擇、風格設定、語言挑選，並自動生成 8~10 頁的分鏡腳本與 AI 繪圖提示詞（支援 Midjourney / DALL-E / Nano Banana 2 等工具）。

## 🔗 快速連結
- [📄 完整系統提示詞 (system_prompt.md)](./system_prompt.md)
- [⚡ Raw 純文字一鍵複製連結](複製你步驟四取得的Raw網址)

## 🚀 如何使用？
1. **教師使用**：開啟 `system_prompt.md`，複製全文貼入 ChatGPT GPTs、Poe.com Bot、Claude 或 Gemini 的 Custom Instructions 中。
2. **學生使用**：點擊教師提供的專屬 AI 機器人連結即可開始創作！
